# 地区与章节方案 v1
日期：2026-10-16
状态：全局讨论稿；开发保持暂停。地区名、数量、等级段和时长均为提案，尚未实现或实测。正式游戏名称未定，“余烬镇”暂仅指此前样板。

## 1. 本稿采用的已确认方向
东方幻想与志怪悬疑；男性主角是特殊家族后人，因变故流落，体内寄居被封禁的妖灵，两人是嘴毒师徒。主要体验是连招、打怪、刷宝与培养。采用城镇整备、地区地图选关、选择难度、进图、结算的循环。机关少量、简单；隐藏首领、特殊装备、秘密区域和高难回访是支线重点。主线目标明确，重要选择影响人物命运与结局。

诅咒通过主线节点推进，玩家可以安心停留和刷装备。早先提出的“记忆仪式”等设定尚未确认，本稿不据此写死世界真相。

## 2. 世界与关卡结构
提议短序章加五地区。每区一座可走动的城镇、一张选关地图、六个常规入口、一个章节首领入口、一个隐藏入口，共40入口。

“入口”是选关目录；“任务”是具有实际目标、遭遇、路线或事件的游玩内容。难度、敌人血量或任务文本变化，不自动算成新的独立内容。

地图显示已知入口、解锁条件、推荐等级、难度、主要掉落与目标装备进度。主线关键线索、伙伴招募保证随正常流程触发；隐藏内容承担额外回报。

主线行动目标依次为：
找到稳定寄居状态的方法 → 追查家族封禁线索 → 查明家族变故 → 找到解除危机的办法 → 决定主角与妖灵的去路。

### 2026-10-16已确认的故事骨架

- 家族因守护禁忌遭灭门，主角追查背叛者。
- 背叛者是家族内部受信任、主角曾真心敬重的长辈；为力量与利益主动出卖守护者，不把核心动机改写为被迫救人。具体姓名、辈分与手段待定。
- 妖灵希望找回失去的身份与力量，自身只有部分记忆。
- 妖灵曾相信强者决定秩序，主动与人族开战，确实是家族需要封禁的危险存在；如今双方重新认识彼此，妖灵重新审视自己的观念。
- 祝听澜为唯一明确女主，灵动又有分寸，平时喜欢逗主角，危险时沉着可靠；集中制作完整感情线。姓名仍沿用暂名。

建议主线连接方式：沈砚寻找稳定寄居的方法，追查家族守护的禁忌；妖灵逐段恢复的记忆与外部证据交叉印证，把求生、灭门调查与封禁真相接在同一旅途上。

家族守护有其依据，妖灵过去的危险也有事实；它与主角现在的信任通过共同经历建立。不用一句幕后操控取消所有责任。妖灵记忆的来源、准确度和缺口要有边界，重要结论不能只凭一段突然恢复的回忆。

仍待设计：禁忌具体是什么、战争经过及妖灵造成的具体伤害、长辈姓名辈分与背叛手段、家族封禁的代价、最终解决办法。以上未决细节不视为用户已确认。

必须理解的事实随正常主线获得，隐藏内容补足旁证、人物经历与额外奖励。背叛者何时正式揭晓，取决于后续身份与事件设计，不用拖延姓名制造空悬念。

## 3. 序章：断桥夜行
主角随行的队伍遇袭，家传物件异动，妖灵帮助其脱险，双方暂时无法分离。序章用实际战斗教授移动、普攻、闪避和一个技能，让玩家取得并更换第一件武器。

内容目标暂定20～30分钟，须实测。下一步目标明确为“前往临川镇，寻找能辨认封禁的术师”。家族背景通过短事件逐步交代。

为支持安心刷宝，建议序章先取得可靠的临时压制办法，第一章再找到更稳定的控制方式；危机随明确主线事件推进，不反复宣称只剩几小时，不设置现实倒计时或定期治疗开销。

## 6. 正常与高难的内容差异
正常主线承担新机制教学与成长。高难回访增加敌人组合、招式变体和机制协同，并提供外观、成长上限与挑战追求；不单靠增血延长战斗。

所有玩法核心机制装备都应有正常难度获取途径。主线不要求先刷齐毕业套装。高难、隐藏、毕业装分别列内容量，不自动算进主线时长。

## 7. 首次通关时长：已确认包含自愿培养
2026-10-16用户确认：第一次从开局到结局，包含正常、自愿的刷装备与队伍培养，整体约30小时以上。此前A／B口径问题已解决；不再要求所有30小时都是独立必经主线，也不把通关后挑战计入首次通关。

建议用以下制作目标继续拆分。这里的分配是新的策划建议，尚未实测，不是用户已经确认的精确小时数：

| 内容 | 建议目标 | 计量方式 |
| --- | --- | --- |
| 主线新内容、必要城镇事件与教学 | 20～24小时 | 按正常首次体验，不依赖毕业套装或重复刷装 |
| 结局前自愿培养、刷目标装备和补充探索 | 10～12小时 | 单独记录返刷、队伍尝试与可选探索，避免重复计算 |
| 首次开局到结局合计 | 约30～36小时 | 代表性玩家的体验目标，不保证每人相同时长 |
| 通关后高难、隐藏与毕业培养 | 另列 | 不用于填补首次通关预算 |

未在结局前完成的隐藏内容属于通关后时间；结局前完成则只计入一次可选探索。菜单、加载和纯等待不是内容制作量。玩家想直接推进时应能正常前进，不强制凑套装、攒固定轮次材料或反复打旧关才允许看结局。

所以确认计入自愿培养，并不代表40入口已经足够。按上述建议分配，独立必经内容仍需扩充约12～19小时量级；自愿培养的10～12小时也需要真实目标和掉落体验支撑，不能只填一个预计数字。

下一轮将为关卡目录安排真正不同的任务阶段、路线、遭遇与事件，再比较需要新增多少地图、敌人和首领。仅换任务文本、血量、怪物数量或收集数量不按等量新内容承诺。此前“180段任务凑30小时”的情景不再作为本轮制作方案；任务数量待内容拆解和代表关卡实测后确定。

培养时间依靠有选择的目标装备、不同角色打法、机制武器、套装及正常与高难回访获得。提高难度、隐藏关和整套毕业均为玩家可选择的追求，不把随机掉落等待伪装成剧情门槛。

验证时分别记录：首次推进、首次可选探索、重复刷装、失败重试、菜单与等待，以及看到结局的时间。快速推进者可能更早通关，偏爱培养的玩家也可能超过36小时；不因此向主线加入强制返刷。

## 8. 制作顺序与验收
先建立城镇、选关、战斗、结算、成长、回城保存的完整系统；地区目录可先规划，但未制作内容明确显示状态。

随后用代表流程验收：城镇整备 → 选关与难度 → 三人轮换产生实际收益 → 机制装备改变打法 → 完整首领 → 掉落结算 → 回城再挑战。达到角色、场景、界面与音效的统一基准后，再按地区扩充。

“先大框架”意味着功能互通、数据可填充、状态可保存，不等于完成五个占位按钮。一个代表关卡需实测首刷与熟练重刷时间，记录战斗、走路、对话和等待，重新校准完整版内容量。

## 9. 视觉方向与代表场景

采用用户偏好的精致像素角色与有纵深的3D场景：斜角镜头、层叠建筑、局部暖光、冷暖空气层次和水面反射，形成可走入的微缩舞台感。以东方古城、山门、边塞与妖市建立自己的世界辨识度。镜头远近、角色像素密度、方向数量和灯光成本，须在实际战斗场景中一起决定。

| 层面 | 美术执行方向 | 验收重点 |
| --- | --- | --- |
| 城镇 | 有生活细节的店铺、灯火、行人小事件和空间层次 | 能认路，商店与任务交互清楚，停留有氛围 |
| 战斗场景 | 3D地面与建筑体块，统一比例的像素角色、怪物和特效 | 出招距离、敌我轮廓与地面危险可辨认 |
| 光与景深 | 局部灯火、雾和远近层次服务地域气质 | 战斗区域保持清晰，不能靠模糊遮盖角色 |
| 装备与觉醒 | 武器轮廓、局部饰件、妖纹与技能表现逐步升级 | 在实机尺寸看得见成长，避免承诺每件衣装完整换装 |
| 界面 | 朴素清楚的地图、背包与掉落说明，辅以纸、铜、符纹细节 | 文字易读，品质不只靠颜色区分 |

建议临川镇与雨灯渡口作为视觉代表场景：暖灯石桥与冷雨码头可同时验证城镇气氛、水面、建筑遮挡、像素角色和混战辨识。先完成一段有完整动作、光效和音效的可玩流程，再扩展五地区资产；这项建议不等于已经恢复制作。

完整外观成长优先使用可见武器、角色进阶装束和觉醒变化。若要求每一件六槽装备都在四人的所有方向和动作上显示，资产量会显著增加，须另立预算。音效同样需要普攻接触、破势、受击、掉落和首领预警的层次，不能只用屏幕震动代替打击感。

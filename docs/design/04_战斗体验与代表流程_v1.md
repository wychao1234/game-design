# 战斗体验与代表流程 v1

日期：2026-10-16  
状态：战斗策划提案；代码开发保持暂停。本文所有按键、距离、时间、血量阈值与时长目标均需未来原型验证，没有新增实现或测试结论。角色与系统规则沿用02、03稿。

## 1. 一场战斗要让人享受什么

以平面斜角即时动作呈现东方志怪冒险：看见敌人的起手，主动接近或绕行，把散开的敌人聚成一组，用选好的技能连贯输出，再换人接住上一人的控制、阵地或标记机会。拾取装备能改变下一趟的打法。画面可以精致，但怪物、地面危险和自己的位置始终优先辨认。

角色在同一地面平面移动，不做平台跳跃或自由高度瞄准。立体场景承担空间与氛围，斜角透视不改变碰撞距离。普通怪可以有短促浮空反馈，玩家不需要依靠复杂空连才能正常推进。

全游戏仍规划四人、进图选三人、一次只有一个受控角色在场。以下四套首轮配置取自既有八个候选中的四个，属于代表体验的制作切片；不会把完整版八选四缩减为永久四招。其余候选保留后续扩展和配装价值。

## 2. PC默认操作与瞄准

| 操作 | 默认输入提案 | 具体行为 |
| --- | --- | --- |
| 移动 | W、A、S、D | 八方向移动；斜向速度归一 |
| 普攻 | 鼠标左键 | 按住连续基础攻击；放开后结束当前攻击，不自动追敌 |
| 普通技能四格 | Q、E、R、F | 朝鼠标方向施放；地面技在合法范围内选择落点 |
| 闪避 | 空格 | 优先按移动方向，无方向输入时沿当前朝向 |
| 切换角色 | 1、2、3；Tab顺序切换 | 数字对应本趟编队槽；倒地角色跳过 |
| 觉醒 | X | 当前角色消耗一次全队共享能量 |
| 拾取／交互 | T | 接近可交互物时显示对象；战斗技能不复用此键 |
| 背包／暂停 | I／Esc | 单人游戏暂停；关内仅查看，不更换装备或技能 |

全部允许重绑定，保存前检测同一场景的键位冲突，并提供左手负担更低的替代布局。Q、E、R、F是首轮试用布局，不据此锁死技能图标位置；默认方案不把同一个按键同时用于觉醒、换人和拾取。

输入优先级为弹窗／界面→技能预览→当前场景操作。打开背包、选关或对话后，点击只作用于界面，不穿透施放攻击；关界面的那次按键不再执行战斗指令。Esc先取消落点预览，再关闭界面，最后打开暂停。城镇内关闭伤害攻击与战斗切换，T只触发明确提示的近处对象；返回战斗时清掉界面期间积累的指令。

鼠标在地面投影的位置决定攻击方向。近战挥砍命中面前扇区，不会因点中远敌自动冲过去；突进技能才改变位置。远程基础攻击朝指针方向发射，按住仍需主动转向。技能配置分别声明“定向即时”“落点预览”“蓄力释放”，不会把全部技能统一成长按。地面预览技能第一次按下显示范围，松开施放；超出射程时钳制到最远合法落点，落点圈清楚提示。取消预览不进入冷却。

可提供轻度辅助瞄准：只在指针附近的小角度内修正到可见目标，不能突然转向身后、隔墙锁敌或改变本应被地形挡住的投射物。设置可关闭；主体验先按手动指向成立，不以自动锁定掩盖操作缺陷。

初拟近战常用有效距离1～2个角色身位、长枪2～3身位、常用远程6～8身位。身位以地面碰撞直径计量，最终换算随模型尺寸和镜头验证。攻击与落点受墙体、关卡边界限制，攻击落空也有明确动作与音效反馈。

## 3. 连招、取消与受击边界

普攻为短连段，最后一击提供收束感；无需玩家持续卡节奏点击。按住普攻也不应把角色锁在长达数秒的动作里。允许在后摇窗口接技能、闪避或换人，提前按下的一次指令可短暂缓存；不能无限缓存整套自动连招。

每个招式明确三个阶段：起手、有效攻击、收招。普通轻击与轻技能开放较早取消；重斩、蓄力和觉醒保留可辨认的承诺阶段。前摇取消且尚未发出攻击，可以不消耗冷却；一旦攻击、召唤或区域已经产生，冷却按施放结算，不因取消、换人、进门重置。取消只能截断剩余动作，不能重复产生同一次伤害。

落点预览可用鼠标右键或Esc取消。后续蓄力技能遵守同一原则：按住蓄力、松开确认；尚未释放时闪避或合法换人会中止，不自动补射；跨越释放承诺点后按招式窗口处理。角色离场时清除其未执行输入，松开旧角色技能键不能触发新角色同槽技能。切换完成本身不产生攻击，持续按住普攻只在新角色合法动作窗口继续普通攻击。

主动换人只在可取消窗口或自由状态执行；承诺阶段按下则提示或短暂缓存，不能借换人绕过全部重招风险。全队换人间隔初拟1秒，从实际完成换人起算。选择当前角色、倒地角色或空槽时只给提示，不换人、不消耗间隔；顺序切换跳过这些槽位。新角色继承合理的地面位置和朝向，不自动接一次免费攻击，也不自动获得无敌。避免在危险区换人仍需靠位置判断和共享闪避。

闪避共享2次充能，初拟逐次恢复、每次约4秒；恢复时间为待测初值。闪避有短暂避伤窗口，窗口的前后仍可受击。切换不补充次数，每人生命独立；关内不会因为切走恢复全部生命。倒地后停止该角色使用并清除其持续效果，强制切换存活者；强制切换保护是否需要单独验证。全队倒地仍保留已取得的经验、装备、材料和永久解锁。

普通受击提供短硬直；高频小伤害采用短暂防连续硬直保护，保护不等于全伤害无效。玩家不被连续击飞后失去操作十余秒。击倒有明确起身窗口，起身保护不能通过主动换人无限续接。回血方式和携带量另作数值议题，本文不临时增加第五种货币或复杂消耗品体系。

### 敌人受到控制的差异

| 对象 | 可受控范围 | 保持反制与阅读 |
| --- | --- | --- |
| 普通轻敌 | 拉拢、推移、短硬直、短浮空 | 一次连续浮空后快速落地，落地短时抗再次挑起；不做无限空连 |
| 普通重敌 | 小幅位移与短停顿，通常不浮空 | 体型与重心提示其重量；仍可聚到有效范围 |
| 精英 | 常态抵抗明显位移；特定攻击可打断，累积破势后短时失衡 | 明示霸体招式与破势反馈；不能每次普攻都压住精英 |
| 首领 | 不被拉走、浮空或常规硬控 | 合法控制技能改为有限破势；破势触发短窗口并有抗连续破势间隔 |

聚怪不会把敌人吸进墙里，也不把不同房间的敌人全拉来。拖枪等技能对不动目标给破势与命中特效，不能只显示“免疫”而失去全部作用。浮空敌人的地面影子标识落点，近战与符术按规定的低空命中带命中；射线不要求精确瞄准画面中的像素高度。

## 4. 四人首轮四技能配置

### 沈砚：贴身连击与印记爆发

首轮选回锋斩、掠影步、灵火签、引印。基础刀击接回锋斩维持连贯，掠影步调整距离；灵火签给选定目标施加自己的印记，引印兑现一次爆发。印记归施放者，不吞掉陆惊弦的标记。切走保留剩余时间，回来仍需自己引爆；不会因后台时间自动无限叠层。

初步起手是灵火签命中精英→掠影步切近侧→普攻和回锋斩→在破绽内引印→收招换人。印记数量上限、持续时长和引爆倍率另测，不用反复刷新一个图标代替实际动作。第一把机制契刀可提案改变引印为较小范围连带爆发，牺牲部分单体收益，基础印记循环仍无需稀有武器才成立。

### 江照野：把战场整理成可输出的形状

首轮选扫堂、拖枪、震关、镇旗。拖枪收拢前方轻敌，扫堂把松散侧翼压回有效范围，震关打断可打断攻击并贡献破势。镇旗留下不伤害的短时援助区域，减少被小伤害打断的风险，不能让站旗里的人无视首领重击。

他的主动普攻与枪击是正常伤害来源；不带迎锋、回马也能流畅游玩。面对不吃拉拽的首领，把拖枪作为有限破势手段，优先把长枪距离用于保持输出。机制长枪可奖励“聚拢后首次震关”的破势效率，但不让旗帜自动替全队打怪。

### 祝听澜：自主召唤与手动指挥互相配合

首轮选唤灯、缚影阵、驱令、铃震。符铃普攻提供主动远程命中；唤灯召出一只有限寿命灯灵，缚影阵限制普通敌人移动，驱令让已有灯灵朝当前指定目标完成协同攻击。铃震应对贴身小怪，为重新定位留空间。未召唤或召唤已结束时，驱令显示不可用原因，不消耗冷却骗玩家。

灯灵自主攻击可以后台继续，驱令必须玩家当前控制祝听澜时主动施放。手动驱令按一次施放上限贡献觉醒能量，不能按每只召唤、多目标、多段攻击重复计数。后续可用唤犬、朱符等替换四格；首轮不额外赠送第五个普通主动。机制符铃可改变驱令的攻击形状或目标分配，灯灵基础指挥不锁在装备之后。

### 陆惊弦：保持距离、挂标记、找准爆发时机

首轮选连珠、退羽、定星、裂帛。远程普攻保证不放技能也能射击，定星给当前目标施加自己的标记；连珠提供短时集中输出，裂帛兑现标记。退羽按瞄准反方向后撤，距离受边界限制，不穿墙、不自带完整闪避无敌。

站桩连珠与安全退路需要选择，不能一边无限高速走位一边完整输出。切换后已经发出的箭继续飞，未发出的连珠停止；不会留一个弓手在场自主跟打。机制弓可让裂帛偏向穿透直线或邻近溅射，玩家按关卡选择，而非所有武器都只加同一乘区伤害。

四人各有独立觉醒候选，但共享一条初拟100能量的资源，只由当前角色消耗一次。能量来自有效的主动命中并有每次施放上限，后台自动伤害不产能；同关跨房间保留，结算、离开或失败重试清空。早期剧情尚未解锁觉醒时，不因代表演示提前开放。

### 机制装备的首批触发契约

以下四件是行为提案，不代表已经制作或正式确定名称。每件启用前必须填入来源角色与技能白名单、允许来源类别、单次施放上限、多段多目标共享规则、有效窗口及清除条件。默认禁止自动召唤、后台区域和派生伤害再次触发装备；修改当次招式形状也不算再手动施放一遍，不额外重置冷却或产能。

| 机制方向 | 唯一允许的来源 | 单次上限与行为 | 失效或禁止项 |
| --- | --- | --- | --- |
| 契刀改变引印 | 沈砚手动施放引印 | 每次施放只做一次范围改形，初拟最多影响3目标，单体收益作为交换待测 | 范围命中不继续生成引印，不由灵火或后台伤害自动引爆 |
| 长枪接震关 | 江照野手动拖枪有效命中 | 本人获得一个约6秒的“下次震关”标记；新拖枪替换而非叠层，手动震关只消费一次 | 多目标拖枪仍只生成1个标记；切人不刷新时限，倒地或离关清除 |
| 符铃改变驱令 | 当前控制祝听澜手动驱令 | 一次驱令只分配一次强化命令，初拟合计最多2个目标；多灯灵、多段共享本次施放上限 | 灯灵自主攻击不触发；驱令攻击不再生成驱令，不额外按每只灯灵产能 |
| 机巧弓改变裂帛 | 陆惊弦手动裂帛 | 把本次攻击改为一次直线贯穿，初拟最多3目标；标记结算仍只发生一次 | 穿透命中不再次施放裂帛，不引爆其他角色的印记 |

首次有效命中、装备改形、后续命中与产能使用同一施放ID归集；多目标或同一帧命中不会重开额度。上述数量与6秒窗口均为待测初值；未来其他机制必须单独登记，不以一条通用“无限触发”回调代替。这些机制改变形状或衔接收益，基础职业循环仍不依赖稀有装备。

## 5. 三套可执行轮换

| 场景与编队 | 操作示例 | 主要判断 |
| --- | --- | --- |
| 密集杂兵：江、祝、沈 | 江拖枪→扫堂→镇旗；换祝唤灯→缚影阵→驱令；换沈灵火签→回锋斩→引印 | 先让敌人进圈，再用爆发；不为了轮换硬等所有技能转好 |
| 首领破绽：江、陆、祝 | 江用震关累积破势；祝唤灯并主动驱令；安全窗口换陆定星→连珠→裂帛，危险前退羽调整 | 首领不被拉走；破势窗口内优先选择当前适合的输出者 |
| 分散远近敌：陆、沈、祝 | 陆普攻牵制远敌、定星；换沈掠影步处理侧翼；换祝铃震解围并放灯，确认安全后再回陆兑现仍有效的标记 | 标记可能到期，换人不保证最佳收益；共享闪避必须留给真实危险 |

这些是打法例子，不做固定按键宏或唯一正确队伍。元素反应矩阵不作为首轮前置。队伍缺少某个人仍能正常过普通关，效率和手感可以不同。

后台预算严格沿用系统稿：自主召唤全队最多2单位；伤害区域每来源角色1个、三人总计3个；非伤害援助区每角色1个、同名取强；短妖影只完成有限一次攻击；陷阱每来源每技能1个。各类分别计数，不能施一个阵误删另一人的召唤。伤害归原角色，切换不刷新寿命或借用新角色属性。

## 6. 缚潮舟主：三阶段可读性提案

场地为宽阔石埠与断船组成的固定地面，边缘有明确碰撞，不做不清楚的坠水即死。首领剪影、船钩、铁链与潮水各有固定动作和声响。血量阈值初拟70%与35%，只表示节奏升级；转阶段用短动作提示，不长时间锁血。躲避不要求必须有某个人、觉醒或两次闪避全部在手。

| 阶段 | 招式与提前信息 | 可反击窗口 |
| --- | --- | --- |
| 一：认识船钩 | 横钩：肩部与钩尖朝侧面蓄力，地面显示扇区；直钩：链条绷直并给狭长方向提示，出手后不无限追踪 | 横钩落空后短收势；直钩钉入石埠后回收较慢，侧面可打 |
| 二：潮与锁链 | 扇区招式保留；压潮：抬钩、潮声增大，数条水带依次拍过，先显示顺序并留可走通间隙；召出至多两只短命小怪干扰 | 每轮水带结束，首领整理链条；小怪不会无限补满，处理后有安静输出时段 |
| 三：已学招式组合 | 直钩后接横钩，方向先锁定再出手；收潮：地面分块依次亮起，玩家沿清楚的安全带绕行 | 组合结束有更明确的疲态；完成安全带后提供一段稳定爆发机会 |

初拟主要危险前给0.7～1.2秒辨认时间，三阶段不以单纯翻倍攻速制造难度。需要转移视线的组合预警更长；具体值以像素角色尺寸、帧动画与实际反应验证。高亮轮廓、形状和声音共同提示，不只靠红绿颜色。

首领重招期间不能无限打断；可破势动作与霸体动作有区别。破势带来有限短停顿，但不删除即将覆盖全场的已生成危险。召唤、技能闪光与掉落标签降低遮挡优先级，让钩尖、地面边界和安全带始终可读。玩家能靠步行或一次准备充分的闪避解决单个主要招式，不出现同时覆盖所有安全位置的随机叠加。

## 7. 代表流程与剧情进度分开验证

本节的完整自然流程是第一章内容补齐后的目标。工程D2首批只制作城镇、渡口与独立舟主代表场景：用隔离的预置进度档分别验证双人流程、后期三人回访和首领，不宣称从新档已经能连续通第一章；E阶段补齐R1-01及R1-03～06后，再完成整章验收。测试解锁条件可以检验规则，不能替代尚未制作的关卡。

### 自然进度首刷

临川镇整备→查看R1-02雨灯渡口的任务、正常难度和掉落目录→进入渡口。此时江照野已经在R1-01结束后加入，沈、江双人即可；祝听澜尚未入队，不提前参与轮换。

雨灯渡口分三段：栈桥轻敌练习聚怪；船仓近远混编练习绕侧与换人；最后护送或解救一位江照野认识的被困者，并击败守口精英。首通必得主线线索，救援不使用暗计时，不因一次失误永久错过人物。船闸只做一次简单、可见的操作，开近路与小宝箱，不打断战斗过久。

渡口结算→回城领取任务反馈与整理真实掉落→继续其余主线，完成R1-06后开放独立R1-B缚潮舟主挑战。进入首领关是新一趟，觉醒能量从0开始；普通成长不丢失。击败首领获得常规随机装备、公开资源和首通奖励，第一章收尾后祝听澜按既定剧情加入。

### 后续复刷代表体验

本轮雨灯渡口画面预览明确采用第一章结束、祝听澜加入后的回访：沈砚当前在场，江照野与祝听澜后台，允许保留祝听澜此前主动召出的一个灯灵。它不是渡口首次到达时的阵容，也不要求陆惊弦已经入队。

四人均已按主线加入后的正常存档，可在城镇四选三，选择已解锁的雨灯渡口或舟主关复刷，验证上表三种编队。这是完整技能配置的体验节点，不修改自然进度顺序。

若未来采用专用测试存档提前展示三人轮换，必须标注“测试解锁”，与正式档隔离，不把测试完成标记写回正式档，也不声称早期主线本来就有全队。独立首领入口须遵守其首次剧情解锁，不在R1-02刚开放时偷开。

战斗结束后基础材料自动拾取，装备保留闪光与名称。可用T拾取，未取重要装备进入结算待领取列表，背包满时提示处理，不静默销毁。关内只比较；回城后对比、装备、配置技能并保存，再出发验证改变。新武器至少让一次攻击范围、引印形状或指挥方式产生可观察差异。随机没出目标也能看见印记累积，兑换沿用60／80／100的待测价格和公开目录。

结算、拾取与换装使用同一趟奖励记录，失败也保留已经获得物；首通奖励不重复发放，重复挑战常规收益仍合法。回城确认队伍生命恢复，读取存档后检查物品实例、角色配置、兑换进度与剧情开放一致。

### 待测时长目标

雨灯渡口首次体验暂以10～14分钟为目标，熟练重刷6～8分钟；独立舟主首次挑战连同识招以6～9分钟为目标，熟练战斗3～5分钟。这些是代表关卡的进一步细化；01中各入口6～10分钟仍是早期骨架估算，后续须按逐关目标重算，不能两套数字混用。加载、菜单等待、失败重试另计，不能作为新内容时长。伤害与路径确定后再调整，未做过实机计时。

首次到结局约30小时以上已确认包含自愿刷装备、培养队伍。20～24小时主线及必要内容、10～12小时自愿培养仍是内容拆解提案；这条代表流程不证明全游戏时长达标，也不通过强制毕业套装延长主线。

## 8. 五条有价值的验收标准

1. **玩家能辨认危险并解释失败。** 未看攻略的新玩家能在数次观察后指出舟主至少三类招式的前兆和安全位置；录屏确认伤害判定与地面提示一致。若主要评价是“看不清怎么死的”，优先修正画面与节奏。
2. **轮换产生实际选择而无资源套利。** 三套编队分别完成相应场景，单角色路线仍可通普通难度；反复切换、取消、进门不能刷新冷却、共享闪避、能量和标记寿命。后台效果不因操作角色变化串用属性。
3. **四种操作有可观察差别。** 近战依赖接近与引印，长枪改善敌群形状，符铃依赖主动指挥而非挂机，弓手主动瞄准并管理退路；三位未控制的人类角色不留场自动跟打，召唤和区域严格按各类上限运行。
4. **奖励与恢复经得起真实失败。** 挑选一次随机掉落、一次指定兑换、一次背包满、一次全队倒地和一次回城读档进行验证，检查不丢已得物、不重复首通、不误扣资源；正常装备可以推进，不要求先刷齐目标物。
5. **代表流程具有实际完成质量。** D2分别用隔离预置档验城镇、渡口双人闭环、三种后期轮换和独立舟主；E补齐第一章后，从新档跑完城镇、渡口、后续解锁、独立舟主、招募、掉落、换装与保存。记录首刷与重刷各段时间，D2测试通过不能冒充整章完成。角色动作、命中、音效、危险提示和掉落都有可辨认反馈，测试存档不污染剧情进度，不能以菜单按钮齐全宣告体验完成。

本稿交付的是可供美术、工程、测试共同评审的战斗蓝图。下一步应先统一实际镜头、角色尺寸和场地可读性，再决定恢复开发的具体资产与功能顺序。

# 已确认设计基线

更新：2026-10-21（Asia/Shanghai）。这里整理用户确认的选择，不把策划提案当成已实现功能。当前进度见 [项目工作总账](../PROJECT_WORKLOG.md)。

## 产品与旅程

PC 单人东方幻想即时动作 RPG，斜角镜头、像素人物与立体环境。亲手操作走位、聚怪、连击、技能爆发与首领挑战，获得武器、套装、新能力及成长外观。

参考 DNF 的城镇进图、关卡与难度选择；地区随主线解锁，每个地区以城镇和关卡组织，不按连续大型开放世界制作。少量简单机关，可选隐藏首领、特殊武器、秘密区域；通关旧地区开放高难秘境。

正常首次难度；失败保留已获得装备与永久成长。完整首次到结局约 30h+，包含玩家自愿刷装备与培养，不把重复刷取强塞进主线时长。

## 男主、妖灵与背叛

用户确认男主有姓名、身世与个人故事：特殊家族后人，家族守护禁忌，遭内部受信任、男主曾敬重的长辈为力量与利益主动出卖。主线目标明确，沿途揭露更深秘密。

体内寄居能交谈、借力的封禁妖灵。它只有部分记忆，隐瞒找回身份与力量的目的；曾信奉强者决定秩序，主动向人族开战，因危险被家族封禁。恢复记忆后双方重新认识，不用失忆替它抹去过去责任。

男主嘴硬有趣、会吐槽和害怕，关键时刻可靠。两者像嘴毒师徒，经常斗嘴，逐渐认可。诅咒主要驱动剧情，允许安心探索刷装备、逐渐掌握，不做强制生存倒计时。

主线基本一致，重要选择影响人物命运与结局。故事为游戏性服务，避免长时间打断刷宝和战斗。

## 女主与伙伴

唯一明确女主为 **祝听澜**，使用符铃与召唤术，对人与妖的关系有自己的判断。相处灵动有分寸，爱逗男主，危险中沉着可靠；重点刻画完整恋爱线。

全游戏 3～4 位可培养角色，各自重点刻画，随主线必定加入。工作阵容为四人，出战选三；切换时原控制者退场、新角色登场，围绕技能衔接，不是三人同时自动战斗。后台获得大部分经验，允许偶尔专门培养。

## 战斗、装备与成长

各角色有多种候选技能，出战前选择装备；近战、法术、召唤有组合空间。完整工作预算为每人八个普通技能候选四选，加一次觉醒，即 32 普通技能 + 4 觉醒；这是未来预算。当前预览各四普通招 + 一觉醒，不得标成全部技能库完成。

普通装备大量掉落；重要武器与套装重点设计。随机掉落与材料兑换并行，追求稀有装备也能看见确定进度。保留学技能、职业成长与觉醒方向，具体完整树尚未落地。

当前预览奖励事务已自动入包，地面显示只是标记；不能因旧设计有 T 拾取提案就说已实现手动拾取。操作重绑定、完整任务系统等也须以实际代码验证，不能从设计稿推断完成。

## 视觉与生产约束

目标：精致像素、古城山川、宗门妖异、冷暖灯光、湿润旧材质与适度景深。以用户认可的雨夜渡口原图为固定目标，维持认可的人物尺度。当前用户要求先精修，覆盖此前“先铺大世界再逐步精修”的排期优先级。

制作采用原有多 agent 分工；不使用 Claude Code Game Studios。编码遵循 Ponytail 的读上下文、小而完整的改动、沿用原生能力、保护数据与适量有效验证原则。具体原文来源见 AGENTS.md。

七份设计档案保留历史版本，其中数字、地区名与未实现规则是提案。出现冲突按用户最新明确指示、本文确认基线、当前工作总账、历史提案的顺序判断；实现事实仍须查看代码和证据。

# 装备、技能与成长方案 v1

日期：2026-10-16  
状态：全局讨论稿；开发保持暂停。数量、百分比、时间、掉率和兑换价格均为设计初值，未实现或实测。

## 1. 设计目标与循环

核心循环：城镇整备 → 地区地图选关与难度 → 主动战斗、探索和首领 → 掉落结算 → 更换装备、调整技能与角色 → 挑战新关或回访。

成长应同时提供三种收获：每趟能积累确定资源；偶尔掉落想要的装备产生惊喜；关键机制改变打法。正常主线不以毕业套装为入场门槛，诅咒不催促玩家离开城镇或停止培养。

五地区、40入口、等级上限50和约每区10级均为本轮建议。等级与剧情解锁分开记录，不能因刷得快跳过必要事件，也不能靠数值墙强迫重复刷图补主线时长。

## 2. 出战与技能配置

| 项目 | 本轮建议 |
| --- | --- |
| 总角色／出战 | 4人培养，城镇选3人进图；战斗中1人在场 |
| 普通主动 | 每人8个候选，装备4个 |
| 觉醒 | 每人1个，使用队伍共享能量 |
| 基础操作 | 移动、普攻、闪避、切换不占主动技能格 |
| 常规技能消耗 | 首轮采用冷却，不额外引入MP条 |
| 换人 | 全队共用约1秒切换间隔；本身不提供无敌 |
| 闪避 | 全队共享2次充能；恢复速度待测 |
| 生命 | 每位角色独立记录，不能靠换人回满 |
| 整备限制 | 装备、技能与三人编队在城镇或出发前修改；关卡中不更改 |

主角可以同时选择刀术、灵术和短暂借形。角色职责通过动作、射程和协同特点区分，不通过硬性职业锁死全部玩法。进阶选择先采用可调整专精；转职和觉醒的剧情节点、名称、解锁级数继续讨论。

## 3. 后台效果、换人与资源归属

换人时，已经发出的投射物和合法的持续效果继续运行；原角色停止新的普攻、移动追敌和主动施法。切换不刷新冷却、持续时间、充能或角色标记。

### 效果预算

| 效果类型 | 上限与替换 | 切走后的行为 |
| --- | --- | --- |
| 自主召唤，如灯灵、灵犬 | 全队最多2个单位；同一技能重放替换其旧组；寿命初拟6～12秒 | 保留剩余寿命内的自主行为，不自动续召 |
| 持续伤害区域 | 每角色1个、三人共最多3个；新区域替换自己旧区域 | 继续剩余时间，不顶掉其他人的区域 |
| 非伤害增益区域 | 每角色1个；同名效果取较强者，不重复叠加 | 按剩余时间运行 |
| 沈砚短妖影、延迟刀击 | 各技能最多1个待执行效果；只完成有限的一次攻击 | 攻击后结束，不追敌循环 |
| 陆惊弦一次性陷阱 | 每角色每技能1个；有寿命，触发一次结束 | 重放移除旧陷阱，旧陷阱不因此引爆 |

各类分别计数，不能用“全队只许2个效果”误删其他人的阵地。第四位未出战者不能在本次关卡生成效果。召唤物不能递归生成新的自主召唤；自动派生效果不能反复触发自身。装备触发须标注来源类别和单次上限。

伤害归原施放角色及其装备、被动，不能借切换套用另一人的高属性。本轮建议：施放时记录来源基础伤害参数，命中时读取目标当时防御和合法状态；临时增伤在具体效果说明中只计算一次。因为关内不能换装，这个规则更易理解和核对。最终数值公式留待实现，不能混用快照与实时计算重复获益。

来源角色倒地或退出关卡时清除其持续效果。房间过渡时只保留设计允许跨房间的效果及其剩余寿命，不在加载时刷新；临时陷阱和场地区域随所在房间卸载清理。

### 觉醒能量

共享上限暂定100，释放时只由当前角色使用自己的觉醒，消耗一次共享资源。能量来自主动操作产生的有效命中，每次施放设收益上限；多目标、多段命中不能无限放大收益。

召唤的自动攻击、后台伤害阵、自动派生攻击不产能。祝听澜手动使用“驱令”算一次主动施放，按单次上限结算；召唤技能的初次有效攻击也只能按该次手动施放结算一次。这样她在场主动战斗仍能正常参与充能。

同一次地下城内跨房间保留能量；结算、离开或失败重试时清空，新地下城从0开始。不能靠反复换人、进门、加载存档刷新觉醒。获取速率和首领阶段限制需实测。

### 倒地与失败

倒地角色本趟暂时不能继续使用，自动切到尚存角色；强制切换的短暂保护是否需要、持续多久，后续通过首领测试决定。全队倒地返回城镇或从关卡起点重新挑战，不删除已获得的装备、经验、材料和永久解锁。

回城恢复队伍，重新挑战重置关卡敌人、临时效果与觉醒能量。已领取的首通奖励不重复发放；新的合法重复通关仍获得常规奖励。

## 4. 角色成长与经验

| 情况 | 经验建议 |
| --- | --- |
| 当前操作角色 | 100% |
| 本次三人队中的后台角色 | 90% |
| 已加入但留在城镇的第四人 | 80% |
| 主线任务经验 | 所有已加入角色共同获得 |
| 新加入角色 | 调整到队伍最高等级减1级附近 |
| 落后最高等级至少3级 | 普通战斗经验按基础值150%追赶，替代100%／90%／80%，不相乘 |

切换导致的一次战斗经验归属需采用一致结算规则，不能每帧改归属重复发放；实现时可按击败事件或战斗结算记录确定。以减少后台差距为目标，不鼓励卡最后一击刷倍率。

主线解锁新能力、专精与觉醒；等级提供稳定基础成长。过往投入可保留，技能配置能在城镇免费调整；第一版不设置高额洗点税。

## 5. 装备槽位与内容预算

六槽：武器、衣装、护腕、鞋履、佩饰、戒指。四个品质暂为普通、精良、稀有、传承。品质是价值与表现分层，机制说明仍必须清楚；不能让所有低品质都只剩无意义占包。

| 内容 | 计算 | 完整版初步预算 |
| --- | --- | --- |
| 武器成长模板 | 4类武器×5档 | 20 |
| 通用部位成长模板 | 5部位×5档 | 25 |
| 成长模板合计 | 属性与等级梯度 | 45 |
| 手工机制武器 | 每角色2把 | 8 |
| 主题套装 | 4套×3件 | 12 |
| 独立特殊饰品 | 佩饰或戒指 | 4 |
| 手工机制物品合计 | 不等于独立美术已完成 | 24 |

套装先使用衣装、护腕、鞋履，提供2件／3件效果；武器和两个饰品位留下搭配空间。独立物品与非套装搭配应有有效路线，不能只有穿满一套的唯一答案。

机制示例：契刀武器改变引印方式；长枪武器奖励聚怪后的破势；符铃改变手动驱令；机巧弓改变标记爆发。都只是方向，具体增益要和角色技能一起核对。避免“所有技能伤害大幅增加”掩盖玩法差异，也避免把本应基础顺畅的操作拆成装备才有的功能。

重要机制物品可用灵尘确定性升级到已解锁等级档，保留其机制。这样早期得到喜欢的武器仍有价值。升级成本与是否保留其他属性待数值验证。

## 6. 掉落惊喜与确定进度

### 三种通用资源

| 资源 | 主要用途 | 边界 |
| --- | --- | --- |
| 铜钱 | 常规购买与成长费用 | 不与现实时间体力绑定 |
| 灵尘 | 拆解回收、机制物品升档 | 不做会摧毁物品的失败强化 |
| 秘境印记 | 指定机制装备兑换 | 全队通用，不另加地区币种 |

秘境印记是跨地区通用资源。完成对应正常关卡首次通关后开放其兑换目录；已经获得的印记可以购买已解锁物品。玩家可以回到低级关卡轻松积累，这是单人游戏的便利取舍；后续若调整效率，需明确说明，不能悄悄新增五种地区货币。

### 兑换初值与实际意义

暂定符合条件的正常关卡每次通关获得10印记，短任务是否符合条件须按真实关卡时长与内容统一判定，不能让进门即结算的任务领取相同奖励。

| 精确兑换物品 | 初拟价格 | 无随机掉落时对应通关次数 |
| --- | --- | --- |
| 指定独立饰品 | 60 | 6次 |
| 指定套装部件 | 80 | 8次 |
| 指定机制武器 | 100 | 10次 |
| 三件完整套装 | 240 | 24次 |
| 一武器＋三套装部件＋一饰品 | 400 | 40次 |

40次是可选长期培养例子，不是正常主线必须完成的前置。这里也未包含第二个饰品；不能把该例子称为六槽全部毕业。兑换直接选择具体角色、部位和物品，不使用随机箱，不自动扣款。

### 指定追求与随机掉落

进入关卡前，从该关卡公开列出的合格物品中选一个追求目标。初拟每次合格通关，对这一个目标独立判定一次5%掉落；不是整个池子每件各5%，也不是每只怪5%。普通装备、任务奖励和其他独立掉落另列规则。

10次独立判定至少成功一次的理论概率约40.1%，不是保底承诺，也不是测试结果。确定进度来自每次通关的印记；掉到目标不会没收已攒印记。玩家可换目标，兑换也不清空其他进度。

正常难度能取得所有核心玩法机制。高难可以提供更高数值上限、外观与挑战奖励；具体额外收益待定，不能把某角色完整玩法锁在高难或隐藏随机掉落之后。

## 7. 拾取、对比与整理

铜钱、灵尘等基础资源自动拾取。装备仍有清楚掉落表现：重要物品闪光、音效与名称区分，但首领预警优先，强光不能遮住危险。

背包支持按角色、部位和品质筛选，与当前装备对比，手动锁定物品。批量拆解先显示清单与回收量，排除已装备、已锁定和需要特别保护的唯一物品。空间满时提供回收或暂存规则，不能静默丢失。

第一轮系统不加入耐久消耗、失败毁装、复杂随机洗词条、每日体力或必须联网的日常。后续若增加，应先证明能改善个人游玩体验。

## 8. 保存与结算约定

这些是后续实现需遵守的产品约定，不代表已有代码接口：

- 物品模板有稳定ID，实际物品有独立实例，升级与装备引用不能靠显示名称匹配。
- 一趟关卡与一次奖励发放有独立记录，避免切场景或读档重复结算。
- 首通标记与重复通关收益分开；限制首通重复不应误删正常重刷奖励。
- 保存包含角色经验、装备实例、解锁目录、印记、技能配置和重要选择；不把临时陷阱等战斗对象当永久资源。
- 普通获得物在安全节点及时保存；失败保留成长不等于所有敌人状态也永久保留。
- 升级、兑换、拆解都要使物品与资源同时完成保存，避免只扣钱或只发物品。

读取失败或版本迁移问题需要恢复方案；未来改数值时尽量保留玩家已经获得的物品和关系选择。

## 9. 制作阶段与验收

| 阶段 | 必须能真实完成的流程 | 进入下一阶段的依据 |
| --- | --- | --- |
| 互通框架 | 城镇选关、进图、战斗、结算、回城、保存 | 状态与收益正确串联 |
| 角色与轮换 | 三人职责、后台效果、共享资源、倒地 | 换人有操作价值，无刷新资源漏洞 |
| 装备与成长 | 真实掉落、替换、机制变化、兑换、追赶 | 每趟有进度，装备说明与实际一致 |
| 代表体验 | 一条完整城镇到首领流程及对应画面音效 | 操作、辨识、奖励体验达到统一标准 |
| 地区扩展 | 填充主线、隐藏、人物事件与高难 | 逐关记录时长、资产复用和独特内容 |
| 完整调优 | 经济、难度、表现与恢复存档 | 依据试玩数据调整，不靠估算宣布完成 |

后续验证重点是能否重复触发结算、换人是否刷新资源、召唤归属是否串错、四人经验是否合理、最差掉落情况下兑换是否仍可接受，以及真实首刷时间。当前不恢复开发，也没有新增游戏测试结果。

## 10. 两轮评审后的决策边界

适合先确认的框架：四选三轮换、独立生命与共享资源、六槽、随机与兑换并行、三种通用资源、后台追赶。

仍属待测参数：等级50、8选4技能、1秒切换、2次闪避、100能量、持续效果寿命、经验比例、5%目标掉落和兑换价格。24件机制物品与45个成长模板是内容预算，不是完成数量。

2026-10-16用户已确认：首次通关约30小时以上，包含结局前自愿刷装备与培养队伍。地区稿建议以20～24小时主线及必要内容，加10～12小时自愿培养，作为下一轮内容拆解目标；该分配尚未实测，也不是额外强制刷图要求。

正常主线按普通装备、合理技能配置可以推进；套装毕业、指定机制武器与高难为自选追求。不得为了凑时长提高主线装备门槛、降低掉率或设置固定返刷次数。40入口当前骨架仍不足以证明达标；重复培养、首次探索和通关后挑战分别记时，不重复计算。

# 角色阵容与关系方案 v1

日期：2026-10-16  
状态：全局讨论稿；开发保持暂停。以下姓名、未确认伙伴的性别、招式名称与数量仍为提案，尚未实现或经过试玩验证。

## 1. 已确认方向与本轮提案

已确认：固定男性主角，特殊家族后人；体内寄居被封禁的妖灵；主角嘴硬有趣，妖灵与他形成嘴毒师徒关系。完整游戏培养3～4人，随主线加入；每次只有当前控制者在场，通过换人衔接技能。伙伴有友情，也能发展明确恋爱关系；后台获得大部分经验。

本稿建议总共4位可培养角色、进图选3位。主角偏近战与借灵混搭，其他人分别负责长兵器控场、灵术召唤、远程机巧。这样保留自由搭配，也让四个人有不同的操作理由。祝听澜已由用户确定为唯一女主，使用符铃与召唤术；两男两女的完整阵容分配仍是建议，其他伙伴性别尚未全部确认。

妖灵不另占第五个角色位，也不要求另刷一套经验和装备。

## 3. 主角与体内妖灵

沈砚并非对所有危险都能轻松应付。他会抱怨、害怕和嘴硬，但已经答应的事会设法完成。笑点来自他和妖灵看问题的角度不同；重要后果发生时，允许人物认真表达，不用连续吐槽抵消情绪。

妖灵暂名“乌岐”，可以先作为自称或化名。用户已确认它希望找回失去的身份与力量，自身只有部分记忆；它曾相信强者决定秩序，主动与人族开战，因此确实是被主角家族封禁的危险存在；如今开始重新审视自己。它懂一些古老灵术，也会判断错误、避重就轻。

每段剧情分别标注“它确定知道的”“它隐瞒的”和“它自己也不确定的”，避免把失忆当作随时补设定的理由。主角家族因守护禁忌遭灭门，背叛者是主角曾真心敬重的家族长辈，为力量与利益主动出卖家族；主角调查与妖灵寻找过去互相关联。战争经过、具体伤害、封禁代价和最终去路仍待设计。

关系节奏建议：

1. 序章互相利用：主角想活下来，妖灵需要宿主脱险。
2. 第一、二章试探：教授能力、斗嘴，双方逐步发现对方有所保留。
3. 第三章共同承担：一次能实际影响战斗或救援的合作，使认可有行动依据。
4. 第四章信任冲突：互证一段关于过去危险的记忆，并说明此前隐瞒与记忆缺口，让玩家根据事实判断。
5. 第五章重新立约：决定双方愿意付出什么，回应主角求生目标。

借用力量不引入实时倒计时、日常侵蚀税或刷图惩罚。力量变化通过主线节点解锁；玩家随时能停下来培养。妖灵不能靠一句“早知道”解释所有谜团。

## 4. 各角色的实际玩法

### C0 沈砚：契刀与借灵

核心乐趣是贴近敌人连招、给关键目标挂印、切入时引爆；能够装备刀术、灵术和短暂借形，但持续召唤仍由祝听澜突出。

| 普通主动候选 | 作用 |
| --- | --- |
| 回锋斩 | 连续刀击，衔接普攻 |
| 掠影步 | 向指定方向突进并斩击 |
| 挑月 | 挑起可受控的小型敌人，大型敌人改受破势 |
| 断契 | 中距离重斩，利用敌人破绽 |
| 灵火签 | 短程灵焰攻击并施加印记 |
| 引印 | 引爆自己施加的印记 |
| 借形 | 妖影完成一次夹击后消失 |
| 回响刃 | 留下一次延迟刀击，结束后消失 |

觉醒候选“同契”：主角与妖灵共同完成一段强化攻击。表现身体异变与默契，持续时长、能否取消和伤害预算需试玩决定。

借形和回响刃不是会自主追敌的召唤物；每次只有有限攻击和明确结束，避免主角吞并召唤角色的职责。

### C1 江照野：长枪控场

在故乡曾负责保护商路或居民，调查失踪同伴时与主角目标交汇。他有判断力，也会被旧职责困住。主角的即兴办法与他的稳妥习惯形成摩擦，后续通过共同承担建立友情。

| 普通主动候选 | 作用 |
| --- | --- |
| 扫堂 | 扇形横扫、收拢轻敌 |
| 贯阵 | 直线突刺、穿过敌群 |
| 回马 | 转身反击，奖励判断敌人方向 |
| 迎锋 | 短时架势，成功应对后反击 |
| 震关 | 打断与破势 |
| 拖枪 | 牵引普通敌人，大型敌人采用替代反馈 |
| 镇旗 | 留下不造成伤害的援助区域，帮助站稳和衔接 |
| 裂垒 | 对破势目标使用的重击 |

觉醒候选“百步镇关”。反击是额外收益，不把正常伤害全部绑定极限弹反；普通玩家也能使用这个角色。

### C2 祝听澜：符铃与召唤

她有自己的师承和判断，不只承担治疗或解释设定。面对被封禁的灵物，既能理解其危险，也反对把所有灵物当耗材。她与妖灵可以有真正立场分歧。

她已确定为唯一女主。符铃与召唤是她自身的能力与成长线，不为了恋爱改成被保护的任务角色。她对人与妖的判断能够影响行动，与主角既有亲近也有分歧。性格已确认：灵动又有分寸，平时喜欢逗主角，遇到危险时沉着可靠。她的身世及与家族事件的联系仍待设计。

相处中的玩笑来自观察力、默契和生活细节，危险发生时优先判断与行动。她可以反对主角，也能承认自己的判断有限；主角与妖灵的战争旧账不能由她一句劝和代替处理。她寻找灵册和坚持人与灵相处原则的个人动机，仍是待完善的既有提案。

| 普通主动候选 | 作用 |
| --- | --- |
| 铃震 | 近身震开敌人，提供调整空间 |
| 朱符 | 远程灵术并标记指挥目标 |
| 唤灯 | 召出有限时长的灯灵进行远程攻击 |
| 唤犬 | 召出有限时长的灵犬干扰敌人 |
| 缚影阵 | 布置减速或束缚区域 |
| 聚灵阵 | 提供召唤协同的增益区域 |
| 驱令 | 手动指挥现有召唤物协同攻击 |
| 归铃 | 收回召唤物，并提供防护或调整收益 |

觉醒候选“百灯引渡”，大范围仪式演出不意味着真的生成上百个独立单位。她在场时靠普通攻击、施符和驱令主动战斗；切走后已有召唤物只按剩余寿命运行。

### C3 陆惊弦：机巧远程

最初与主角追逐同一条线索，合作后发现双方的问题彼此关联。她对器物负责，也喜欢尝试新办法。追查亲人和技术流出是一条独立动机，不能只服务主角感情线。

| 普通主动候选 | 作用 |
| --- | --- |
| 连珠 | 快速连续射击 |
| 穿云 | 蓄力贯穿射击 |
| 退羽 | 后撤并射击 |
| 钩索 | 主动调整位置，具体锚点规则待原型验证 |
| 牵丝雷 | 一次触发的有限时陷阱 |
| 定星 | 给目标施加个人标记 |
| 裂帛 | 引爆自己的标记 |
| 散花 | 扇形近身自保射击 |

觉醒候选“天罗落星”。普通攻击本身就应是有效远程玩法，不能只靠技能才能射击；自动锁定、手动瞄准和键鼠手感需后续比较验证。

招募不依赖稀有掉落、限时事件或隐藏好感度。必要个人事件不要求把对应角色编入当前三人组；剧情登场与战斗编队分开处理。

## 6. 轮换与培养原则

每人从8个普通主动候选中装备4个，另有1个觉醒；这是完整版技能预算，具体能力可在试玩后合并或替换。普攻、闪避和切换不占4格。

典型配合包括：江照野聚怪，祝听澜控制或指挥召唤，沈砚切入引印；或江照野破势后，由陆惊弦在安全距离打出标记爆发。队伍不用依赖大量元素反应表，也不锁定唯一正确轮换。

切换不重置技能冷却、闪避次数、印记或召唤寿命。角色独立生命、共享闪避资源和觉醒能量；后台效果、倒地、经验和资源结算详见系统稿。切换本身没有默认无敌。

经验建议：当前角色100%，同队后台90%，第四位80%；落后至少3级时采用150%的追赶系数替代普通系数，不重复相乘。新加入者接近队伍最高等级，避免必须带回低级区补课。上述百分比均为待测参数。

## 7. 友情、恋爱与重要选择

每个角色都需要独立目标、队友互动和共同经历。关系推进以主线事件、可选同行战斗和短城镇对话为主，关键事件可复查；不靠大量重复送礼拖时长。

已确认只制作祝听澜这一条明确女主感情线，重点刻画完整关系，不安排其他伙伴竞争恋爱路线。友情互动同样保留完整人物价值，战斗能力不以恋爱选择为门槛。

建议感情节奏如下；属于事件设计提案，尚未确认具体对白与情节：

| 阶段 | 感情进度 | 与冒险结合 |
| --- | --- | --- |
| 临川 | 认识对方的能力与处事方式 | 在入队前后通过共同处理灵异事件建立第一印象 |
| 栖霞 | 建立信任与日常默契 | 队伍旅途中互相帮助，短城镇事件展现相处细节 |
| 朔风 | 开始主动袒露脆弱与关心 | 面对灭门证据时，各自作出能看见的行动 |
| 烟罗 | 面对真实立场分歧 | 对妖灵风险与解决方式产生分歧，不靠误会拖延 |
| 天隙 | 明确回应关系并共同承担 | 女主仍有自己的任务，结局回应双方的未来 |

重要推进以手工事件和共同经历完成，明示关系进度并可回看。不靠刷礼物、装备稀有度或隐藏好感门槛判定感情结局；具体告白节点、互动尺度与结局变化待下一轮设计。

### 三段关键人物事件提案

1. **救人与取证，临川。** 祝听澜调查灵册相关的异常，与主角目标交汇。她安排有执行办法的救援，再协同取得证据；主角选择帮忙，两人从实际行动了解彼此。首次主线任务保证必要证物，不把救援失败作为永久失去招募或恋爱的门槛。她的灵册目标仍属提案。
2. **旧战场的名字，朔风。** 主线碑录、独立证言与妖灵记忆互证其主动发动战争。它起初仍以统一秩序辩解，逐渐面对被它支配的人与妖的处境。隐藏首领只能补充旁证；关键战争事实不锁在隐藏关。后续以解除遗留控制、接受他人拒绝等行动表现改变，受害者不必原谅它。
3. **长辈的旧承诺，朔风至烟罗。** 证据指向背叛长辈，旧物或回忆也显示他曾真实保护、教导主角。温情与主动逐利背叛可以同时成立。主角根据现在可核实的事实作判断，女主陪伴却不替他原谅，妖灵也不能只鼓动复仇。

以上通过短场景、任务行动和回城交谈推进。新内容的关键事件首次可见，可选交谈增加细节，重复刷图可直接继续战斗；不用长篇独白替代行为。主角变强的乐趣保持完整，妖灵反思的是如何使用力量和对待别人，不把装备成长本身写成错误。

| 角色 | 重要选择提案 | 可见反馈方向 |
| --- | --- | --- |
| 沈砚 | 立即公开家族证据，或先处理可能造成的伤害 | 城镇信任、盟友态度与结局说明 |
| 江照野 | 留在制度中改革，或独立保护当地人 | 他之后承担的职责与居民反馈 |
| 祝听澜 | 重建旧仪式，或建立人与灵的新规则 | 灵物处境、师门延续与个人结局 |
| 陆惊弦 | 有监督地公开研究，或封存危险器物 | 技术流向、支援方式与后续生活 |

选择前提供足够事实，后果通过人物行动、世界状态与结局体现。暂不采用永久删除已经培养角色的惩罚。若故事需要短暂分离，也要明确恢复条件，不能让玩家长期失去常规刷图功能。

通关后回到明确标注的终战前挑战状态继续培养，并保留已看过的结局记录。这能容纳不同结局，也避免把结局后人物状态强行解释为无限刷图。

## 8. 演出与制作预算

32个普通主动加4个觉醒，是36个技能设计条目；再加四套普攻、移动、受击、闪避、倒地、武器动作、换人和召唤表现，资产量显著高于单人样板。不能按36个图标估算工作量。

后续代表流程先用每人3～4个有完整动作和音效的技能证明职责、切换收益和视觉辨识；其余候选保留在数据规划中。此处是制作分批次，不把完整版改成四个技能的小作品。

人像、战斗像素角色与场景统一色彩。每人先锁定站姿、武器比例、四向或八向需求，再扩展动作；斜角镜头下的近战距离和投射物高度要先实测，避免画完大量素材再返工。

## 9. 本轮评审、已确认与仍待设计

本轮由剧情策划、角色策划和独立设计评审分别检查，整合后完成第二轮交叉核对。人物表已同步女主身份与性别的确认状态；个人身世、事件和结局仍保留提案标注。

已确认：祝听澜是灵动有分寸、危急可靠的唯一女主；妖灵寻找失去的身份与力量，曾信奉强者秩序主动与人族开战；家族守护禁忌，却被主角敬重的族中长辈为私利出卖。

本轮已有足够方向进入五章主线与任务策划。剩余的女主身世、战争具体事件、长辈姓名与手段，先由策划提出能评审的方案；不再为每项枝节持续增加问卷。其他伙伴性别、正式姓名和招式名后续再定。

技能效果、切换时间、追赶倍率和动作范围都需要未来原型验证。本稿只完成设计与一致性评审，没有恢复代码开发。

# 渡口实机画面修订

用户指出首版实机与已确认的雨夜码头概念图明显不同。本轮单独修正画面，功能检查不作为美术目标通过的证明。

## 本轮实做

- 以港水、舱船、远岸木屋和灯廊取代贴近战区的整排亮白墙。
- 调整俯角及取景，保留正交尺寸15和角色实际高度；城镇与战斗微跟随，检查边角位置不被HUD遮挡。
- 使用真实三维长短错缝木板、旧损边缘、收尖船体、弧形船舷和垂曲系缆。
- 新木纹albedo、湿干粗糙度、反射、冷色补光、暖色灯笼和接触遮蔽一起构成夜景。
- 像素角色采用自身绘制明暗与统一轻冷色调，保留脚下接触关系，避免环境光使角色融入暗地面。
- 左上改脸部头像，底部改技能图形，敌人改真实生命比例的细血条；技能朝向、冷却、血量均来自实际状态。

## 恢复与素材说明

临时工作区被环境清理后，从已保存的源码恢复；各工程师依据保留的完整变更重建视觉改动，再重新验证。旧截图和旧通过记录不直接用于本轮验收。

木纹原始文件无法找回，已沿原提示重新生成，使用内置imagegen。当前 `assets/environment/dock_aged_wood.png` 为1254×1254 RGB，SHA256为 `7d14a9c821aaec9b45417759208c23afbcd0dd2573ebae86581f9c374a4d95e4`。它是均匀中性照明的灰棕旧木albedo，板缝、雨水反射与灯光由引擎产生；边缘并非严格周期无缝。角色图集未重新生成。

## 验收范围

`tools/capture_art_frame.gd` 使用真实第一波与生产材质，在隔离存档中固定站位拍摄。它是可复现的摆位检查，不能称为人工完整游玩录像。正常流程的动态画面需另行运行。

`tests/camera_bounds_review.gd` 对实际生产镜头投影六处站位，检查头部、脚底和HUD边界。战斗、碰撞、持久化及美术各自留证。

当前是实机视觉修订，尚未据此宣布达到概念图最终精致度。完整攻击/受击/死亡专用动画、建筑与道具的手工细节、最终声音仍需要制作。Windows目标机、实体显卡性能与长时间稳定性尚未验证。

## 本轮独立复核

美术QA实际对照了恢复后的baseline／candidate、人物照明对照、density3与最终 `art-world-final.png`。最终固定帧、来源与资产哈希保存于 `tests/preview_evidence/visual-v2/`，阶段判断保存在 `tests/preview_evidence/art_review_v2.md`。

最终画面实见分簇远岸屋舍、桩廊水隙、收尖船体与系缆、错缝旧木、冷暖夜雨反射、可辨的角色／敌人和蓝色绘画技能图标。相比首版的亮白墙围场、条纹地板、暗人物和大文字格，这些是实际引擎画面的改善。正式镜头采用相对8／14／24、向后港取景（实际位置8／14／21、看向z=-3.5）、正交尺寸15与微跟随，保留角色投影大小。

独立完整功能回归在这些改动接入后重新执行：Godot 4.5.2版本／导入及9个行为用例共11阶段、151项断言全部通过，时间为北京时间2026-10-16 19:41:11；原始证据和源码SHA位于 `tests/preview_evidence/summary.json`。这是新版本结果，不能解释为画面自动评分。

专项日志也保存在 `tests/preview_evidence/visual-v2/`：世界78项／0失败且831格连通，正式镜头6站位头脚投影无失败，HUD atlas实际runtime加载20映射全部通过。这些分别验证技术契约，不与151求和，也不等于原图风格匹配；镜头专项退出的ObjectDB警告如实保留于日志，长时稳定性仍未验收。

总体结论是**显著更接近目标的视觉修订**。远岸屋顶／窗式仍较重复，湿旧材质与生活道具细节、景深层次和专用动作仍有手工精修空间，尚不能称与原概念图相同。固定摆位图、连续帧录像、规则检查、Windows执行与性能各自保留边界；固定步长离线录像的20fps不代表用户电脑实际可达到20fps。

## 实际短片检查范围

本轮另实际录制Godot Movie Maker短片：1440×810、161帧、8.05秒，20fps固定模拟步长，编码为H264／AAC MP4。日志与元数据保存在 `tests/preview_evidence/visual-v2/visual-movie.log` 和 `movie.json`。独立QA打开按2秒间隔的4张抽帧，实见江照野／祝听澜换入、技能图标和冷却变化、普通／精良装备自动入囊标签、旗环、敌人与青色召唤／术法效果。新版城镇和舟主实帧也已打开复核，截图及已审抽帧保存于同目录。

这段演示未覆盖完整四人、三波和三阶段通关，也不证明所有红色预警、完整专用动画、连续帧无闪烁或人工操作手感。掉落标签密集时的避让和建筑／道具手工细节仍需后续精修。软件Vulkan离线产片成功不等于Windows目标机或实体显卡性能验收。

# 临川 · 渡口代表试玩

这是东方幻想动作刷装游戏的开发样板。当前提供临川镇整备、地下城选择、雨灯渡口三波战斗、独立缚潮舟主三阶段挑战、结算回城，以及真实的经验、装备、指定兑换和保存流程。它是代表流程，尚不包含完整第一章、五地区剧情或30小时内容。

本包为实机视觉修订版：更新港口与船体、湿旧木板、雨夜灯光、镜头、人物显色和头像/技能图标。与目标概念图仍有建筑道具细节和专用动作方面的差距，详见 `docs/VISUAL_REVISION.md`。存档格式仍为2，沿用现有代表试玩存档，无需清档。

## Windows 运行

1. 将 `linchuan-preview-windows-x64.zip` 完整解压。
2. 打开 `Linchuan` 文件夹，双击 `Linchuan.exe`。
3. `Linchuan.exe` 和 `Linchuan.pck` 必须放在同一目录。首次启动可能等待着色器编译。

无需安装 Godot、Python 或开发环境。目标为 Windows 10/11 64位、支持 Vulkan 的显卡与驱动，使用 Godot 4.5.2 Forward+。当前没有真实 Windows 目标机启动和实体显卡性能验收。

若启动异常，使用同目录 `Launch.bat` 再启动一次并保留 `runtime.log`，同时记录系统版本和显卡型号。

## 推荐体验顺序

先在城镇选择三名出战队员，进入雨灯渡口熟悉移动、普攻、四技能与轮换；清理三波敌人后结算回城。再挑战独立的缚潮舟主，观察不同阶段的地面危险提示与进攻空隙。回城查看背包、换装，选择想追求的装备，积攒秘境印记后指定兑换，再次挑战比较打法变化。

四人是本代表试玩的测试预置，不是正式剧情中已经同时加入。正式版仍按主线陆续招募。沈砚使用契刀，江照野使用长枪，祝听澜使用符铃与召唤，陆惊弦使用机巧弓；出战三人、当前仅一名人类角色在场，后台已部署效果可以持续。

## 战斗操作

| 按键 | 操作 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 指向攻击方向/技能落点 |
| 左键 | 普攻 |
| Q / E / R / F | 当前角色的四个技能 |
| E按住后松开 | 有区域预览的技能显示落点，松开释放 |
| 右键 | 取消当前技能落点预览 |
| X | 消耗队伍共享觉醒能量，释放当前角色觉醒 |
| 1 / 2 / 3 | 切换对应出战位 |
| Tab | 轮换至下一名可行动队员 |
| 空格 | 闪避，队伍共享两次充能 |
| T | 城镇靠近渡口、器物摊或告示牌交互；战斗结束后回城 |
| I | 查看背包；城镇中可换装、指定兑换与拆解，战斗中仅查看 |
| M | 城镇中打开地图，选择关卡、难度和本趟追求装备 |
| P | 城镇中调整三人出战编队 |
| Esc | 优先取消技能预览，其次关闭面板，否则打开暂停菜单 |

具体技能、冷却和当前可操作状态以画面提示为准。切换角色不会刷新技能或闪避资源；未满觉醒能量时不能释放觉醒。

## 装备、兑换与保存

击杀和通关会产生经验、普通装备与材料。后台角色也获得经验，等级与装备会影响实际战斗；四把机制武器分别改变对应角色的技能表现，守渡套装支持2/3件效果。

每次有效通关获得10枚秘境印记；当前兑换价为佩饰60、单件套装80、机制武器100，需先满足界面显示的解锁条件。追求目标随机掉落与确定兑换并行，重复游玩可以积累进度。不要将同一次结算反复打开视为新一次奖励。

已有装备和成长在战败后保留。新代表试玩使用独立存档 `linchuan_preview_v2.json`，不覆盖旧矿井的 `ember_save.json`。保存系统有有效备份恢复与双坏档保护；界面提示停用保存时请保留原文件，避免手工覆盖。

## 画面与完成度

使用斜角近距离镜头、像素角色与立体场景，保留暖灯与冷色雨夜的方向。当前人物使用步行图集与程序化攻击反馈；完整专用攻击、受击、死亡动画和最终音效配乐仍待制作。概念目标图不等于实机完成度。

云端逻辑检查和软件 Vulkan 实渲染能证明对应功能与画面在测试环境工作，不能推出目标电脑帧率、Windows已运行或最终操作手感。

## 源码与复现

固定使用 Godot **4.5.2 stable 标准版**。官方引擎和同版模板：
https://github.com/godotengine/godot-builds/releases/tag/4.5.2-stable

导入 `project.godot`，按 F5 运行新代表试玩；旧 `main.tscn` 保留为矿井回归入口。

```text
python tools/build.py --godot /absolute/path/to/Godot doctor
python tools/build.py --godot /absolute/path/to/Godot run
python tests/run_preview_qa.py --engine /absolute/path/to/Godot
python tests/run_qa.py --engine /absolute/path/to/Godot
python tools/build.py --godot /absolute/path/to/Godot export-windows --template /absolute/path/to/4.5.2.stable/windows_release_x86_64.exe
python tools/build.py source
```

上述 Python 命令只供开发复现；下载 Windows 试玩的玩家不需要执行。构建脚本不联网安装软件，不修改正式工程设置，在隔离副本中导出。`BUILD_INFO.json` 记录引擎、模板、源码和产物哈希，并明确区分导出成功与 Windows 目标机执行。

引擎许可证位于 `LICENSES/Godot-MIT.txt`，字体许可位于 `LICENSES/Noto-CJK-copyright.txt`。

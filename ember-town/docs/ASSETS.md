# 素材与来源

- 主角、敌人、召唤物：本项目使用内置图像生成创建的原创角色图集，经过透明主体边界识别、共享比例、脚底锚点与最近邻归一化。原始生成图与引擎图集均包含在源码中，提示约束见ASSET_PROMPTS.md。
- 场景模块与像素纹理：本项目程序化制作。
- 武器、地面预警、法术与掉落效果：本项目代码创建。
- 中文字体：Noto CJK，按SIL Open Font License分发，许可证见LICENSES。
- Godot运行时：MIT许可，许可证见LICENSES。

当前为矿井战斗与掉落样机，不含完整城镇、任务、多房间、觉醒或商业级完整动作。角色目前使用移动循环和独立武器，专用攻击/受击/死亡动画仍待扩充。没有使用参考游戏截图或提取素材。

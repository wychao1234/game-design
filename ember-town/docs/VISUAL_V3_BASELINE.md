## 五项门槛

| 门槛 | 通过所需的实际结果 | 拒绝条件 |
| --- | --- | --- |
| 1．两种尺度都有收益 | 同v2正式镜头、站位、光照和分辨率对照。正常游戏画面能辨出三组物件的材料／结构改善；从同一实帧取原尺寸100%局部，绳结有可信缠绕和接点，箱桶有板端／箍带／装载层次，瓦窗有合理接缝／旧色。分别留前后证据 | 只在额外放大、换灯或隐藏旧物之后显得更好；只加噪声／重复线条，正常视图看不出改善；用更多物件或shader数量代替结果 |
| 2．焦点与原场地不退步 | 维持冷暖夜雨、旧木PBR和主角／敌人／预警可读；新细节留在原物件局部，原有通路、边界、交互点与战斗留白不变 | 货物／绳结进入主战区遮挡角色或危险；材质恢复成高频条纹、镜面火柱、纯色黑面；新增碰撞／改关卡来制造好看截图 |
| 3．16帧身份与解剖逐帧成立 | 每一方向逐格与现有 `assets/characters/shen.png` 比较：同一发髻／脸型／深色衣装／浅色腰巾／红色左臂；无红缠布的右手持续握同一柄契刀，红色左手不变为主持刀手。前后左右用身体方位判断，不能按屏幕左右误判 | 换脸／换衣／换刀，手指与刀柄断开、刀穿身、双刀或额外肢体；任一背向帧把刀换到红色左臂；靠镜像交换红臂与武器位置 |
| 4．动作在实际尺寸连贯 | 四方向都能看出接触→随挥→收势→回位，而非步行循环。逐帧叠看头身比例、脚底锚点与接地阴影，正常速度和慢放均无明显全身缩放、脚底漂移、跳格或末帧弹回。合法步法可以改变姿势，不能让整个人无理由滑动 | 仅把人物移动／旋转或添加刀光当专用斩击；自动按每帧包围盒缩放导致身高呼吸；格边裁掉刀尖／手脚；靠重新居中掩盖身体漂移 |
| 5．可见接触与真实命中同拍 | 保持已授权的instant damage：按下有效攻击的同一模拟步已经结算命中，首个可见攻击姿势须处于接触／挥出阶段，刀身、挥弧、朝向与实际受击目标一致。分别实际验证普攻／Q／E／觉醒，含前方命中和背向／隔墙不命中；结束／合法取消／切人后回到正确状态 | 画面仍在明显蓄力却已掉血，或刀弧／目标相反；动画另加一次伤害、换人刷新攻击或连按错播；用16格数量与自动功能总数替代动作评审 |

## 固定对照与证据

- 普通视图沿用v2生产镜头：正交size15、候选实际位置8／14／21、看向z=-3.5及既有微跟随规则；局部对照用相同站位固定镜头，不把取景变化算作材质收益。100%局部是原生像素裁图，不是插值放大或另开高倍率镜头。
- 源角色以现有shen PNG／JSON为身份和尺寸参照。对16个新帧逐一登记方向、格号、持刀手、身体比例、脚底、刀尖边界及通过／拒绝理由。坏帧必须点名，不因同表其他帧良好而让整套通过。
- instant damage不改为延迟打击。工程须给出实际模拟时间／事件与当前攻击帧的对应记录；没有这项证据，仅看合成图不能确认时序一致。
- 顺序为源图逐帧筛选→同相机真实静帧／原尺寸局部→实际动作短片与慢放→受影响功能回归。素材落盘即通知主控持久保存，再进入长渲染。
- 等主控统一导入后再运行新验证；并行制作期间QA不导入、不改生产源。v3未验证前不沿用v2的151项通过，也不宣称完整四角色专用动画、手工画面最终精度或目标机性能完成。

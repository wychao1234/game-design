# 实机美术交付门槛

用户最新要求：**达到最开始确认的渲染图效果再发。**

正式参照为 `reference/approved-ferry-target.png`，已从原保存图片恢复并实际核对，与用户贴出的渡口战斗图一致。它是概念美术目标，不能用作运行背景、实机截图或完成证据。元数据与内容哈希见同目录JSON。

必须在真实可玩场景中满足：

- 人物占画比例、动作辨识与参考一致；近战挥弧、受击、地面预警清楚，其他人类队员通过切换登场。
- 码头形成前景旧瓦与灯笼、中景战斗与装卸货物、后方横船及通透水道、远岸错层古建的空间层级。避免完整裸露的矩形测试台、重复等高房盒和大块无纹理表面。
- 旧木有可信磨损、板缝和不连续湿反光，水面有疏密变化的冷蓝细波及灯下碎倒影。局部细节、正常游戏尺度与动态画面都需成立。
- 暖灯与冷雨水色有主次，演员清晰，景深只服务前后层级，不以模糊掩盖制作缺口。
- 普通渡口、首领场景、移动和攻击分别实际审查；测试通过、素材数量增加或比上一轮好看，都不等于达到整体目标。

当前版本仍为内部开发迭代。未通过上述整体美术验收前，不更新对外交付截图、视频和试玩包。每轮保留真实失败点与检查点，不能将概念图重新生成后作为实机成果。

# 角色素材生成记录

执行方式：内置图像生成；透明背景。

## 主角
原创银发冒险者，深蓝长衣、青绿围巾、棕色皮靴、黄铜肩扣，空手中性持握。复古JRPG像素造型，约35度斜俯视。4列4行：南、北、西、东四朝向，每朝向4帧行走；同角色、同尺度、稳定脚底、无文字和场景、真实透明。

输出：assets/hero_source.png 原始图，assets/hero_sheet.png 引擎图集。

处理：按4x4切格，以alpha>128的主体边界计算裁切；全帧共用缩放比例，将最大角色高度归一为54像素，放入64x64单帧、脚底62像素。最近邻采样，透明背景保留；最终图集256x256。

## 敌人
原创腐化矿井守卫，风化深铁铠甲、锈铜配件、灰色兜帽、骨质面孔、暗红眼睛，空手。与主角一致的复古像素尺度，4列4行，南北西东四朝向、各4帧移动；稳定尺度、脚底，无字、无地面、真实透明。

## 召唤物
原创白面青蓝色幽灵狐，尖耳、可读深眼、卷曲灵体尾、金色额纹。横向4格等距悬浮循环，体积和画布位置稳定，明确像素簇、真实透明、无场景与文字。

本记录给出可复用的主要提示约束。AI输出须检查透明、尺寸、跨帧一致性，再进行引擎动画验收。
